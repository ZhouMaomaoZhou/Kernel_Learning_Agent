# HTML 版式参考

在讲解提纲和图形语义明确后，需要具体版式起点时，读取[模板选择表](references/selection.md)，只打开与当前关系匹配的样例。样例来源于 lewislulu/html-ppt-skill 的固定版本，MIT 许可和改动范围见[来源记录](references/upstream.json)及[许可](LICENSE)。

1. 写清本节要解释的关系和读者要做的判断，再选择版式。已有页面组件能表达时继续复用。
2. 取用所需的布局、间距或图形骨架，替换示意内容，沿用当前页面的字体、颜色和交互约定。节点、边、分层、日期与比较字段由 Case 的证据决定。
3. 默认静态完整展示。分步骤或切换能帮助跟踪条件变化时，再接项目已有的阅读组件。信息密集的连续阅读页按内容延展，布局遵循 [HTML 阅读环境](../visual-design/references/design.md#阅读环境)。
4. 将模板中的技术标签、关系和数值逐项核对，再按项目的 technical-review 与 visual-review 检查最终产物。复用代码时保留上游 MIT 声明及出处。

这里收录六种静态版式。制作完整演讲幻灯片，需要翻页、演讲者视图或主题运行时时，再按[选择表中的上游入口](references/selection.md#完整幻灯片与更新)读取对应模板和运行条件。
