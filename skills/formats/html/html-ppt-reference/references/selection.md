# 按讲解关系选择模板

样例可直接在浏览器离线打开，所有内容均为示意。选择后把当前 Case 的实体、条件和来源放回对应位置。

| 本节解释什么 | 本地模板 | 取用之前检查 |
| --- | --- | --- |
| 有先后的调用或数据交接 | [流程](../assets/layouts/flow-diagram.html) | 节点写清角色，箭头写清参数、结果或等待条件。分支和汇合按机制补画。 |
| 组件、数据或职责怎样分层 | [架构](../assets/layouts/arch-diagram.html) | 分层表示归属。要表达调用顺序时另标边，跨层联系需有证据。 |
| 两个候选在相同条件下的取舍 | [对照](../assets/layouts/comparison.html) | 字段、单位和负载对齐，结论附近给出处，配色依据比较含义。 |
| 一段代码怎样实现一个决定 | [代码](../assets/layouts/code.html) | 给完整版本、路径与行号，解释输入和输出。过长时按需展开上下文。 |
| 一次改动修改了哪个条件 | [变更](../assets/layouts/diff.html) | 保留必要前后文与增删符号，说明触发条件和验证结果。 |
| 一条机制怎样随版本演进 | [时间线](../assets/layouts/timeline.html) | 每个节点有版本和出处。等距排布表达顺序，耗时或比例需有真实尺度。 |

适配模板使用系统字体与本地 CSS，适于连续阅读。箭头、层次及空白只承载表内说明的关系。源码和截图等工程图展示时保留完整内容，按需提供带提示的局部滚动。

## 完整幻灯片与更新

来源固定于 [lewislulu/html-ppt-skill / fd1629067909ff55b36b905476de4e5f26062a1f](https://github.com/lewislulu/html-ppt-skill/tree/fd1629067909ff55b36b905476de4e5f26062a1f)。

- 需要完整演讲页时，先读上游该版本的 [Skill](https://github.com/lewislulu/html-ppt-skill/blob/fd1629067909ff55b36b905476de4e5f26062a1f/SKILL.md)及对应模板。确认内容与读者后选择运行时，结合已有授权决定操作。
- 本地只选取六个单页模板的布局样式，替换了示意内容和页面外壳，增加响应式规则。本地资源为独立 HTML 与 CSS。上游原模板可能引用字体服务、代码高亮 CDN 或固定平台路径，使用前检查离线资源和当前环境。
- 引入另一版模板时，先比较需要的文件及其依赖，保留 MIT 许可，更新来源记录中的 commit、原路径、blob 和 SHA-256。适配后按 [HTML 阅读环境](../../visual-design/references/design.md#阅读环境)查看成品。按当前任务需求更新选用项。

本项目的提纲、来源与审查流程仍从[技术学习工作流](../../../../../workflows/technical-learning.md)进入。
