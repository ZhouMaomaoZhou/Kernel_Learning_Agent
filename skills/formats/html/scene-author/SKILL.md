# 自主步进场景

只有状态变化有助于读者追踪因果时采用。先完成 [visual-design](../visual-design/SKILL.md)。

1. 为场景记录 `id/question/claim/source_ids/steps`。一个核心问题贯穿各步。每步标发生的变化、参与对象和新增结论；例子和技术边界始终一致。静态对照保留单一状态。
2. 源码入口贴着相应动作。为每个场景只打包相关事实和固定来源。超预算时按教学问题拆开，让每段都可独立解释。
3. 保留读者控制的步进和重置；可定位到具体步骤。交互切换不改变图例语义。展示逻辑顺序时用步骤表达，测量才用时间尺度。
4. 跑场景检查，实际打开受影响场景的截图；检查关键初态、改变后的状态和回到起点。工具与许可见 [HTML 场景工具](../../../../docs/visual-tooling.md)，验收用 [visual-review](../visual-review/SKILL.md)。
