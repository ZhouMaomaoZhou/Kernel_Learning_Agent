# HTML 视觉设计

## 选图

从每节的问题出发，写一句结论、图形的数据依据、读者先看哪里、是否需要交互。整页沿用提纲中的例子。顺序、范围、状态或比较关系决定图形。

| 要看懂的关系 | 适合的表达 |
| --- | --- |
| 谁负责什么，数据由谁接手 | 带边标签和边界的职责/数据流图 |
| 什么条件触发另一条路径 | 标明判定点的小型分支图，配一个变化前后的输入 |
| 状态怎样产生、等待、消费和复用 | 对齐角色的泳道图；跨时刻用离散步骤 |
| 相同口径下的取舍 | 对齐的表或图，单位、条件和来源靠近比较对象 |

把概念图里的调用、数据、等待与覆盖分别标识。只有切换状态能帮助读者理解机制时才加控件，相关图、文字与数值一起更新。测量证据支持时才用长度或速度表达耗时。

## 构建

选图之后读 [视觉规范与组件](references/design.md)。需要版式起点时，按需加载 [html-ppt-reference](../html-ppt-reference/SKILL.md)，根据关系选择一个局部模板。一节一个视觉焦点，先给结论和主图，再给说明与证据。需要逐步揭示时读 [scene-author](../scene-author/SKILL.md)。构建产物交给 [visual-review](../visual-review/SKILL.md) 走读。
