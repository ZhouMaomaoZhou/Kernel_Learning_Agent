# 视觉规范与组件

## 阅读环境

本项目的 HTML 学习页面向桌面浏览器，制作和验收使用桌面窗口。任务已给窗口尺寸时沿用该尺寸，否则以 1440×950 作为起点；交互检查包含键盘、鼠标和页面滚动。对比列、图形、公式与源码按实际可用宽度排布，必要时使用有提示的局部滚动。

## 版面与组件

把页面排成一篇可以浏览和回读的技术文章。用标题、主图、短解释和贴近结论的来源建立节奏。首屏交代读者要解决的问题、对象的职责和一条进入主线的路径。每章开头用一句结论接回上一章留下的值或问题。

- **版面。** 正文使用舒适的行宽和有节奏的段间距；主图可比正文宽。用留白划分章节，少用等权卡片。先移走重复说明和次要证据，再调整密度。按目标窗口组织并排对照，空间不足时调整列数或使用有提示的局部滚动。
- **颜色。** 默认可用暖白底、深墨正文和一种克制的强调色。用颜色表达同一对象、当前路径或状态，辅以文字、线型或边界。辅助分支降低视觉权重，同时保留清晰对比。测量与推导用就近标签区分。
- **图形。** 先看得到主体和流向，再看得到数字。节点旁标角色，边上标传递的值或条件。跨视图保持同一对象的命名和位置线索；并排对照用同一尺度、单位和分母。
- **交互。** 默认状态完整可读，额外控件靠近它改变的图。切换应能预测结果、回到起点并保留可见焦点。源码、完整谓词和补充账本从对应机制进入，展开后仍能回到上下文。

`web/reader.js` 的 `mountFigure` 与 `web/reader.css` 支持局部步骤、URL 恢复和来源入口，mHC 和 Model PR history 使用这套组件。场景检查和截图入口见 [HTML 场景工具](../../../../../docs/visual-tooling.md)。按案例的既有构建命令生成离线 HTML。
